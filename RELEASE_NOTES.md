# STORM GBCA 1.7.1

## Русский
- **Хэш загруженного буфера после предзагрузочного мягкого патча:** смежный патч (`.ips`, `.ups`, `.bps`) теперь применяется до включения блокировки Hardcore, а хэш RetroAchievements (`storm_gbca_get_loaded_ra_hash`) вычисляется непосредственно по загруженному в память ROM, чтобы поддерживаемые хаки и переводы корректно определялись; мягкое патчирование во время игры в Hardcore остаётся заблокированным.
- **Усиление Hardcore Gatekeeper (Core + Android + Windows):** переход Casual -> Hardcore выполняет полную чистую перезагрузку ядра с очисткой патч-читов в ROM, блокирует отключение системного RTC, внешние Link Cable / Wireless / IR / Dolphin JoyBus (разрешён только GB Printer), а неофициальные достижения (`Flags == 5`) полностью исключены из активации и отправки `h=1`.
- **Безопасность Connect API, Encore и офлайн-очереди:** поиск обложек RA на Windows переведён на HTTPS POST с единым 3-сегментным User-Agent (`STORM-GBCA/1.7.1 (...) mgba/0.11.0` / `sameboy/1.0.5`) без передачи токенов в URL; добавлена проверка JSON `"Success": true`, устранена повторная отправка уже полученных трофеев в режиме Encore, выровнены параметры `r=ping` и очистка уже открытых элементов в очереди.
- **Синхронизация интерфейса и горячих клавиш:** в настройках Windows заблокированы переключатели Rich Presence, Leaderboards и Unofficial при активном Hardcore, исправлен учёт пользовательских клавиш QuickSave/QuickLoad и отображение индикатора ускорения, а на Android добавлена мгновенная синхронизация Hardcore из `SettingsActivity`.
- **Юридическая точность и унификация MPL-2.0:** все исходные файлы C# приведены к единому заголовку **MPL-2.0**, `PRIVACY_POLICY.md` честно описывает автопроверку обновлений при запуске, оба пути офлайн-очереди и точный список внешних доменов, а `THIRD_PARTY_LICENSES.md` уточняет `mGBA 0.11.0-dev`, `zlib 1.3.2`, `LZMA SDK` и исходники `librashader`.

- **UI, Hotkey & Mid-Session Sync Fixes:** Windows settings lock Rich Presence, Leaderboards, and Unofficial toggles while Hardcore is active, `SingleScreenSessionView` honors remapped QuickSave/QuickLoad keys and Hardcore FastForward limits, and Android `SettingsActivity` synchronizes mid-session Hardcore changes immediately.
